# Player probability methodology

BreakMetric now calculates category-level probabilities for an individual player.

## Base parallels
For base cards #1–200, each eligible subject is modeled as one card in the 200-card standard base pool. Refractor and Prism quantities use the Topps per-box quantities; the remaining base-parallel rows use official Hobby pack odds.

Max Dowman #201 is not mixed into the 200-card pool. Topps publishes separate Hobby odds for #201, so those exact-card odds are used separately.

## Inserts
Every mapped Hobby insert section uses the official Topps odds mapping. The five common 20-card themes share Topps' pooled 100-card odds, so a player's share is based on the number of physical checklist cards featuring that player inside the 100-card pool.

## Autographs
Main Chrome Autographs and mapped special autograph sections use the official Hobby odds plus the physical checklist size of that section. A player appearing on a dual/triple/quad card receives that physical card in the player's personal hit probability.

This does not decide break ownership for multi-team cards. Ownership rules remain a separate model.

## Important limitation
The model assumes equal likelihood within a checklist pool unless Topps publishes card-level weighting. Published odds rows are combined with an independence approximation. Future collation evidence can refine this.
