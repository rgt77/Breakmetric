# BreakMetric v1.1.1 hardening

This hardening block follows the v1.1 provenance release and focuses on production safety rather than new analysis features.

## Release gates

- Product, format and analysis routes must resolve to committed files.
- Every JSON dataset must parse.
- Ready-format case/pack/card arithmetic must be internally consistent.
- Inline application JavaScript and source modules must pass syntax checks.
- Spot price and currency are persisted atomically.
- FX changes are committed only after every required rate has loaded.
- ROI remains withheld until EV coverage and market-source requirements pass.
- EV/ROI are presented as beta while no team is ROI-ready.
- Combined player hit probability discloses its cross-category independence approximation.

GitHub Actions runs these checks on pull requests and pushes to main.
